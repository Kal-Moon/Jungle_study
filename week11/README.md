## 공통으로 본 관점

1. **유지보수** — 규칙을 바꾸거나 새 종류를 추가할 때 고칠 곳이 한 곳인가. 종류별로 다른 처리는 `Map` 표로 모았다.
2. **보안** — 사용자 입력이나 저장된 값이 HTML·스크립트·이벤트 속성으로 DOM에 들어가는 길이 있는가.
3. **극한 상황** — 규모를 키워 어디서 무너지는지 보고, 고칠지 한계로 문서화할지 정했다.
4. (다음에 할 것) **최적화** — 저사양 PC에서도 렉이 없게.

## 실행

각 폴더가 따로 실행된다. ES Modules라 `file://`로는 안 열리므로 그 폴더에서 정적 서버를 띄운다.

```bash
python -m http.server 8000
```

- 데모: `http://localhost:8000/`
- 테스트: `http://localhost:8000/tests/index.html`
- 극한 테스트: `http://localhost:8000/tests/stress/index.html`
